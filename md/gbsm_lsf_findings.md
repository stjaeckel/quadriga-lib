# Findings on the spec `md/gbsm_lsf_spec.md`

Review findings of the spec for the QuaDRiGa large-scale model port. Each reviewer appends its findings to the table
below with the next free ID (F-1, F-2, ...); the spec writer fills in the resolution and changes the spec accordingly.

Severity: **blocker** (the spec cannot be implemented as written, or it contradicts a decision), **major** (wrong
formula, missing behaviour, untestable requirement), **minor** (ambiguity, inconsistency, wording).
