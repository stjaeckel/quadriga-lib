About Quadriga-Lib

Quadriga-Lib is an open-source C++ library with MATLAB, Octave and Python interfaces for radio channel modelling and simulation. It generates channel impulse responses for system-level studies of mobile radio networks. It also provides tools for array antennas, channel data storage and processing, and site-specific (ray-tracing) simulations.


Who it is for
  • Researchers and engineers who need realistic radio channels for link- and system-level simulations, antenna array studies or ray-tracing post-processing. Install it with pip install quadriga-lib and try the example below.

  • QuaDRiGa users. Quadriga-Lib is the C++ successor of the QuaDRiGa MATLAB channel model, by the same lead developer. It is not a drop-in replacement: functions, names and file formats follow their own API. QuaDRiGa-NG is a fork of the MATLAB toolbox that uses Quadriga-Lib in its backend.

  • Standardization work. The library implements the 3GPP TR 38.901 stochastic channel model and the IEEE 802.11 indoor channel models (TGn, TGac, TGax, TGah). The publications describe the implementation and compare the two model families.

Features
  • Stochastic channel model (GBSM): large-scale and small-scale fading parameters, path loss, LOS probability, O2I loss, and scenario parameters for 3GPP TR 38.901
  • IEEE 802.11 (Wi-Fi) indoor channel models: TGn channel types A to F with the TGac, TGax and TGah extensions (MU-MIMO, floor penetration loss, time-evolving channels)
  • Spatially consistent random fields: sum-of-sinusoids generators for correlated random variables
  • Array antennas: predefined models (omni, dipole, ULA, 3GPP panels, multibeam), pattern interpolation, rotation, coupling, directivity and beamwidth, QDANT file format
  • Channel coefficients: antenna patterns applied to path data (spherical and planar wave, multi-frequency, IRS), baseband frequency response, delay quantization, delay and angular spread, K-factor, XPR
  • Channel data storage: HDF5 channel files for large datasets (read, write, reshape)
  • Site-specific simulation: ray–triangle and ray–point intersection, mesh tools, OBJ and Mitsuba XML export, reading of QRT ray-tracing results
  • Acoustics (experimental): room-acoustic simulation with the ray tracer, loudspeaker models and acoustic material tables; under active development
  • Fast core: C++17 with OpenMP, optional AVX2 and CUDA acceleration

Quick start (Python)

Install the package from PyPI:

pip install quadriga-lib

Create a 2 × 2 3GPP antenna array at 3.7 GHz and print the directivity of its first element (about 9.8 dBi):

import quadriga_lib

ant = quadriga_lib.arrayant.generate('3gpp', M=2, N=2, freq=3.7e9)
print(quadriga_lib.version())
print(quadriga_lib.arrayant.calc_directivity(ant, 0))

The same example for MATLAB, Octave and C++ is on the download page. The Python, MATLAB / Octave and C++ API references have more examples.
