About the Library
  • How is Quadriga-Lib related to QuaDRiGa?
    QuaDRiGa is a geometry-based stochastic channel model written in MATLAB. Quadriga-Lib is its C++ successor by the same lead developer: the model components are being rewritten in C++ for speed, with thin interfaces to MATLAB, Octave and Python. It is not a drop-in replacement for the MATLAB toolbox; functions, names and file formats follow their own API. QuaDRiGa-NG is a fork of the MATLAB QuaDRiGa toolbox that uses Quadriga-Lib in its backend.
  • How do I cite Quadriga-Lib?
    If you use Quadriga-Lib in published work, please cite the software and the version you used. The installed version is returned by quadriga_lib.version() in Python, quadriga_lib.version in MATLAB / Octave and quadriga_lib::quadriga_lib_version() in C++. Publications on the models are listed on the Publications page.
@software{quadriga_lib,
  author  = {Jaeckel, Stephan},
  title   = {Quadriga-Lib: C++/MATLAB/Python library for radio channel modelling and simulation},
  url     = {https://github.com/stjaeckel/quadriga-lib},
  version = {<version>},
  year    = {<year>}
}
  • Is the API stable?
    Quadriga-Lib is under active development. Breaking changes are avoided where possible, but they do happen between releases. For reproducible results, use a release version and note it, or check out a release tag of the GitHub repository. The main branch may be ahead of the latest release. The API documentation on this site is generated from the source code of the latest release.
  • Which compilers are supported?
    Quadriga-Lib needs C++17. It is built and tested with GCC 11 or newer (GCC 12 by default on Linux) and with MSVC 2022 on Windows.
  • MATLAB reports a "GLIBCXX ... not found" error when loading the MEX files. What can I do?
    MATLAB ships its own, older C++ runtime (libstdc++). MEX files built with a newer GCC than your MATLAB release supports fail to load with this error. The build uses GCC 12 by default. If your MATLAB release needs a different version, install it (e.g. sudo apt install g++-11) and build with make gcc_version=11. The compilers supported by each MATLAB release are listed by MathWorks.
  • Can Quadriga-Lib be used together with other C++ libraries?
    Yes. Quadriga-Lib uses Armadillo for its matrices and cubes. To exchange data with other libraries, create Armadillo objects that use auxiliary memory, use their STL-style iterators, or get a pointer to the matrix memory with .memptr().

Bug Reports and Contact
  • How do I report a bug?
    Open an issue with the bug report form on GitHub. The most useful part is a small, self-contained example that shows the problem, together with the library version and the interface (C++, Python, MATLAB or Octave). Please search the existing issues first; if your problem is already there, add your case as a comment.
  • How do I request a feature?
    Use the feature request form. Describe the task you want to solve, not only the function you have in mind.
  • Where can I ask how to use the library?
    Ask in GitHub Discussions. You can also share your results there.
  • How do I report a security problem?
    Please do not open a public issue. Use GitHub's private vulnerability reporting instead; only the maintainer sees the report.
  • How can I contribute code?
    Small fixes are welcome as pull requests on GitHub. For anything larger, please open an issue first so the approach can be agreed before you write code. Contributions need tests and documentation; see CONTRIBUTING.md.
  • Who develops Quadriga-Lib?
    Lead development is done by Stephan Jaeckel.
  • How can I contact the developers?
    By email to "info [ÄT] quadriga-lib [DÖT] org". For bugs, feature requests and usage questions, GitHub is preferred, so that other users can find the answers.

Distribution License
  • What is the distribution license for Quadriga-Lib?
    Quadriga-Lib is licensed under the Apache License 2.0, a permissive license. See also a quick summary of the license.
  • Can I use Quadriga-Lib in commercial products without releasing the source code?
    Yes. Quadriga-Lib can be used in open-source and proprietary software. If you distribute it, in source or binary form, keep its copyright and license notice (the LICENSE file) with your software or its documentation.
  • How does the Apache License compare to the GPL, MIT and BSD licenses?
    Unlike the GPL, the Apache License does not require you to publish the source code of software that uses Quadriga-Lib. It is a permissive license like MIT and BSD, and it also grants users the patent rights of the contributors.
  • Is Quadriga-Lib a product of the Apache Software Foundation?
    No. It only uses the Apache License.
