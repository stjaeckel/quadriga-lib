/*!SECTION_DESC
- **How do I report a bug?**<br>
  Open an issue with the <a target="_blank" rel="noopener noreferrer" href="https://github.com/stjaeckel/quadriga-lib/issues/new?template=bug_report.yml">bug report form</a> on GitHub. The most useful part is a small, self-contained example that shows the problem, together with the library version and the interface (C++, Python, MATLAB or Octave). Please search the <a target="_blank" rel="noopener noreferrer" href="https://github.com/stjaeckel/quadriga-lib/issues?q=is%3Aissue">existing issues</a> first; if your problem is already there, add your case as a comment.

- **How do I request a feature?**<br>
  Use the <a target="_blank" rel="noopener noreferrer" href="https://github.com/stjaeckel/quadriga-lib/issues/new?template=feature_request.yml">feature request form</a>. Describe the task you want to solve, not only the function you have in mind.

- **Where can I ask how to use the library?**<br>
  Ask in <a target="_blank" rel="noopener noreferrer" href="https://github.com/stjaeckel/quadriga-lib/discussions">GitHub Discussions</a>. You can also share your results there.

- **How do I report a security problem?**<br>
  Please do not open a public issue. Use GitHub's <a target="_blank" rel="noopener noreferrer" href="https://github.com/stjaeckel/quadriga-lib/security/advisories/new">private vulnerability reporting</a> instead; only the maintainer sees the report.

- **How can I contribute code?**<br>
  Small fixes are welcome as pull requests on <a target="_blank" rel="noopener noreferrer" href="https://github.com/stjaeckel/quadriga-lib">GitHub</a>. For anything larger, please open an issue first so the approach can be agreed before you write code. Contributions need tests and documentation; see <a target="_blank" rel="noopener noreferrer" href="https://github.com/stjaeckel/quadriga-lib/blob/main/CONTRIBUTING.md">CONTRIBUTING.md</a>.

- **Who develops Quadriga-Lib?**<br>
  Lead development is done by <a target="_blank" rel="noopener noreferrer" href="https://sjc-wireless.com">Stephan Jaeckel</a>.

- **How can I contact the developers?**<br>
  By email to &quot;info [&Auml;T] quadriga-lib [D&Ouml;T] org&quot;. For bugs, feature requests and usage questions, GitHub is preferred, so that other users can find the answers.
