Pointing an agent at the docs

Give your agent the address of llms.txt and ask it to fetch only the sections it needs:

Read https://quadriga-lib.org/llms.txt, then use the Python API section files
to write a script that generates a 3GPP antenna and prints its directivity.

The same Markdown files are in the GitHub repository, so an agent working in a clone can read them without network access.
