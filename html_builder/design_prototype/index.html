Realistic radio channels for mobile and Wi-Fi network simulation

Open-source library built on the 3GPP TR 38.901 and IEEE 802.11 channel models. A fast C++ core with MATLAB, Octave and Python interfaces, from the developer of QuaDRiGa.

Quick start

Create a 2 × 2 3GPP antenna array at 3.7 GHz and print the directivity of its first element, about 9.8 dBi.

pip install quadriga-lib
import quadriga_lib

ant = quadriga_lib.arrayant.generate('3gpp', M=2, N=2, freq=3.7e9)
print(quadriga_lib.version())
print(quadriga_lib.arrayant.calc_directivity(ant, 0))
ant = quadriga_lib.arrayant_generate('3GPP', 1, 3.7e9, [], [], [], 2, 2);
disp(quadriga_lib.version())
disp(quadriga_lib.arrayant_calc_directivity(ant, 1))
#include <quadriga_lib.hpp>
#include <iostream>

int main()
{
    auto ant = quadriga_lib::generate_arrayant_3GPP<double>(2, 2, 3.7e9);
    std::cout << quadriga_lib::quadriga_lib_version() << "\n";
    std::cout << ant.calc_directivity_dBi(0) << " dBi\n";
}

What it covers

From standard channel models to site-specific simulation and data storage.

Stochastic channel model3GPP TR 38.901 large- and small-scale parameters, path loss, LOS probability, O2I loss
IEEE 802.11 channelsTGn types A to F with the TGac, TGax and TGah extensions
Array antennas3GPP panels, ULA, multibeam; interpolation, rotation, directivity, QDANT files
Channel coefficientsSpherical and planar wave, multi-frequency, IRS, frequency response
Site-specific simulationRay–triangle intersection, mesh tools, OBJ and Mitsuba export
Channel data storageHDF5 channel files for large datasets
Fast coreC++17 with OpenMP, optional AVX2 and CUDA
AcousticsexperimentalRoom acoustics with the ray tracer; under development
