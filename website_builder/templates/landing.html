Quick start

Create a 2 × 2 3GPP antenna array at 3.7 GHz and print the directivity of its first element, about 9.8 dBi.

{% filter highlight("bash") %}pip install quadriga-lib{% endfilter %}
{% filter highlight("python") %}
import quadriga_lib

ant = quadriga_lib.arrayant.generate('3gpp', M=2, N=2, freq=3.7e9)
print(quadriga_lib.version())
print(quadriga_lib.arrayant.calc_directivity(ant, 0))
{% endfilter %}
{% filter highlight("matlab") %}
ant = quadriga_lib.arrayant_generate('3GPP', 1, 3.7e9, [], [], [], 2, 2);
disp(quadriga_lib.version())
disp(quadriga_lib.arrayant_calc_directivity(ant, 1))
{% endfilter %}
{% filter highlight("cpp") %}

    std::cout << ant.calc_directivity_dBi(0) << " dBi\n";
}

What it covers

From standard channel models to site-specific simulation and data storage.

Stochastic channel model%%GAP: 3GPP TR 38.901 large- and small-scale parameters, path loss, LOS probability, O2I loss%%
IEEE 802.11 channels%%GAP: TGn types A to F with the TGac, TGax and TGah extensions%%
Array antennas%%GAP: 3GPP panels, ULA, multibeam; interpolation, rotation, directivity, QDANT files%%
Channel coefficients%%GAP: Spherical and planar wave, multi-frequency, IRS, frequency response%%
Site-specific simulation%%GAP: Ray–triangle intersection, mesh tools, OBJ and Mitsuba export%%
Channel data storage%%GAP: HDF5 channel files for large datasets%%
Fast core%%GAP: C++17 with OpenMP, optional AVX2 and CUDA%%
